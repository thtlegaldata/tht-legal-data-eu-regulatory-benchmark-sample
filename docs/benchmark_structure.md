# Benchmark Structure

The full THT Legal Data benchmark is organized around regulatory segments aligned across all 12 covered EU languages.

Each alignment group corresponds to one regulatory segment and links the language versions of that segment.

## Core organization

Core structural levels may include:

- legal act;
- CELEX identifier;
- article;
- paragraph;
- point or subpoint, where applicable;
- fine-grained segment order;
- language version;
- source traceability;
- QA status or review metadata.

The public sample illustrates this structure using a very limited number of entries and a limited number of languages.

## Alignment groups

In the public sample, each `alignment_group_id` links the English, French and German versions of the same regulatory segment.

The full benchmark follows the same general principle across all 12 covered EU languages.

## Source traceability

Each public sample entry includes a CELEX identifier and an EUR-Lex source URL for the relevant language version.

The public sample is intended to show how regulatory segments can remain traceable to official EU legal sources.

## Public sample limitations

The public sample does not expose the full benchmark, all covered languages, internal QA metadata, complete annotation layers, or production-ready evaluation formats.
